# Shape Check — 시연 웹 앱 4차

수상한 메시지 캡처는 기기에 두고, 필요한 항목만 검토해 사기 수법과 비교하는 정적 앱입니다. 국제 심사 명세에 따라 영어로 시작하고 앱바에서 한국어로 전환합니다. 데스크톱에서는 원본과 확인 결과를 나란히 비교하고, 모바일에서는 보낼 내용부터 확인합니다.

## 열기

`index.html`을 파일로 열거나 폴더 전체를 정적 호스팅에 올리세요. 기본 모드는 서버·가입·설치·외부 CDN 없이 작동합니다. 글꼴과 이미지도 포함되어 있습니다. `#scene-1`부터 `#scene-5`까지 직접 이동할 수 있습니다.

2차 파일 전체는 `../web-old/`에 보관했습니다. 3차에서는 화면 구조와 반응형 스타일을 다시 구성하고, 기존 데이터·공유·기록·오프라인 처리·하이브리드 어댑터를 재사용했습니다.

3차 파일 전체는 `../web-old/round-3/`에 보관했습니다. 4차에서는 피드백에 맞춰 직접 입력값 보존과 미리보기 문구만 수정했습니다. 디자인과 `shot.mjs`는 그대로 유지했습니다.

## 4차 변경

- 직접 입력 폼의 입력·선택 이벤트마다 임시 값을 메모리에 보관합니다. 창 크기를 바꿔 화면이 다시 그려져도 입력값이 남습니다. 검증은 제출할 때 수행하며, 입력 중인 값은 저장소나 서버로 보내지 않습니다.
- 직접 입력한 원본은 영어로 `Original: typed by you · 0 personal details`, 한국어로 `원본: 직접 입력, 개인정보 0개`라고 표시합니다.
- 영어·한국어에서 390px와 1280px를 왕복하고 제출했을 때 빨강 판정과 전송 내용이 유지되는 회귀 검사를 추가했습니다. 미리보기의 거래 여부·평소 연락 경로 선택값도 확인합니다. 브라우저 검사에는 전체 화면 캡처 후 제출하는 재현 과정도 포함했습니다.

## 장면

| 장면 | 상황 | 확인 결과 |
|---|---|---|
| 1 | 택배 수수료 사칭 | 빨강, 공식 배송 조회 안내 |
| 2 | 실제 배송 안내 | 초록, 앞선 사칭 메시지와 비교표 |
| 3 | 새 번호로 연락한 가족 사칭 | 빨강, 원래 번호로 전화 안내 |
| 4 | 은행 계좌 정지 사칭 | 빨강, 개인정보 5개 가림과 전송 내역 |
| 5 | 기기 안 AI 없음 | 전송 중단, 직접 입력 후 검토·확인 가능 |

상단 안내 띠에서 상황·할 일·성공 조건을 확인하고 다음 장면으로 이동합니다. 결과를 확인한 뒤에도 안내 띠를 계속 볼 수 있습니다.

## 3차 변경

- PNG와 개인정보 좌표를 같은 렌더러에서 생성합니다. 브라우저 렌더러는 글꼴 로딩과 레이아웃 안정화를 기다린 뒤 좌표를 잽니다. 좌표는 바깥쪽으로 반올림합니다.
- 가림막은 완전히 불투명한 직사각형입니다. 같은 이미지 영역을 기준으로 원래 글자보다 사방 2 CSS px 넓게 덮습니다. 글자가 들어갈 공간이 없으면 자물쇠만 표시하고 전체 항목명은 접근성 이름으로 남깁니다.
- 모바일에서는 보낼 핵심 항목과 Check 버튼을 먼저 배치합니다. 받은 곳·거래 여부는 펼쳐 확인할 수 있고, 원본은 아래에서 별도로 펼칩니다. 데스크톱에서는 모든 항목과 원본을 펼쳐 둡니다.
- Check 뒤에는 결과 카드로 이동합니다. 하단 탭 높이와 안전영역만큼 본문 아래 공간을 확보합니다. 모바일 사진 선택 영역에는 키보드 붙여넣기 안내를 표시하지 않습니다.
- 전송 전에도 원본 이미지·개인정보 개수와 보낼 글자 수를 확인할 수 있습니다. 줄 삭제·되돌리기·맥락 변경 때 글자 수가 갱신됩니다.
- 모의 클라우드 판정에 경과 시간을 표시하지 않습니다. 실제 로컬 판독·Live 호출에만 측정한 시간을 표시합니다.
- 하단에 가상 메시지·가상 인물임을 명시합니다.

## 운영 흐름

가입 없이 사용합니다. Check를 누르기 전에 전송 동의 문구와 보낼 내용이 나옵니다. 사진은 사용자가 선택하거나 직접 붙여넣습니다. 원본 이미지는 저장하지 않습니다. 결과와 오프라인 대기 항목은 이 기기의 저장소에만 보관하며, 앱을 열 때 7일이 지난 기록을 삭제합니다. 브라우저가 닫힌 동안 실행되는 삭제 작업은 없습니다.

기록은 100건까지 보관하고 10건씩 표시합니다. 검색·판정 필터·CSV 내보내기·전체 삭제가 있습니다. 가족에게는 원본 대신 판정 카드와 확인 항목을 복사해 전달합니다. 클립보드 권한이 없으면 선택해서 복사할 수 있는 텍스트로 바뀝니다.

오프라인에서는 확인한 항목만 저장하고 다시 연결되면 처리합니다. 직접 입력 오류는 수정할 내용을 보존합니다. 잘못된 이미지, 기기 안 AI 미지원, 취소, 시간 초과, 빈 기록도 처리합니다.

## 실행 모드와 한계

- 기본: 사전 준비한 로컬 출력과 수법 규칙 대조. 설치 없이 5개 장면을 체험합니다. 판정은 모의 실행입니다.
- Chrome Prompt API가 있는 기기: 사용자가 고른 사진은 실제 기기 안 모델로 읽고, 클라우드 단계는 규칙으로 재현합니다.
- Live: `firebase-config.js` 설정과 로컬 `vendor/` SDK가 필요합니다. 현재 설정은 비어 있고 SDK는 포함되어 있지 않습니다. 실제 Firebase·App Check·Gemini Nano 동작은 이번 작업에서 검증하지 않았습니다.

`hybrid.js`에서 이미지 입력은 `ONLY_ON_DEVICE` 경로에만 전달합니다. 클라우드 사용자 입력은 화면 전송 내역과 같은 문자열입니다. 모의 실행은 네트워크를 사용하지 않습니다. 실제 서비스의 판독 정확도나 사기 판정 성능을 측정한 자료는 아닙니다.

## 검사와 캡처

```sh
node --check poc/web/app.js
node poc/web/test-dom.mjs
PW_ROOT=/path/to/playwright-parent node poc/web/shot.mjs
PW_ROOT=/path/to/playwright-parent node poc/web/test-web.mjs
PW_ROOT=/path/to/playwright-parent node poc/web/test-web.mjs https://host.example/subdirectory/
```

`PW_ROOT`는 `require('playwright')`를 할 수 있는 디렉터리입니다. DOM 검사는 `DOM_ROOT`에 jsdom 설치 위치를 지정할 수 있습니다. 기본값은 이 작업 환경의 `/tmp/shape-check-validation`입니다.

`shot.mjs`는 샘플 PNG와 좌표를 먼저 갱신하고 `_codex/shots/demo-<장면>-<폭>.png`에 결과를 저장합니다. 390×844·1280×800의 5개 장면 외에 첫 화면, 전체 화면, 모바일 원본 펼침, 직접 입력, 한국어 결과도 캡처합니다. 모바일 결과 캡처는 자동 이동한 위치를 유지합니다.

`test-web.mjs`는 두 크기에서 가림막의 실측 좌표·불투명도·라벨 맞춤, 첫 화면 Check 위치, 결과로 스크롤, 하단 가림, 전송 문자열, 판정, 해시·뒤로가기·새로고침, 오프라인·공유·CSV, 외부 요청 0건을 검사합니다.

현재 검사 결과와 실행 제약은 `QA.md`에 기록했습니다. DOM 검사는 브라우저 화면·실제 네트워크 검사를 대신하지 않습니다.
